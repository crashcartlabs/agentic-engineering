# Claude Code adapter

Read and follow `AGENTS.md` in this directory. It is the canonical repository policy for every supported agent harness.

Shared skills live in `skills/` and shared agent prompts live in `agents/`. Claude-specific project settings may remain under `.claude/`, and the installable Claude plugin is described by `.claude-plugin/plugin.json`; neither location owns shared workflow content.

If these instructions conflict with higher-priority system, developer, or user instructions, follow the higher-priority instruction.
